# Protofilio

بورتفوليو شخصي لـ **ميار أحمد** — مطور واجهات أمامية (Front-End Developer).

موقع ثابت مبني بـ HTML و CSS و JavaScript، مع تصميم متجاوب بالكامل، ووضع ليلي/نهاري، وقسم مشاريع مع فلترة ديناميكية.

## 🛠 التقنيات

- **Angular** — الإطار الأساسي للتطوير
- **Next.js** — للتطبيقات المساندة
- **TypeScript**
- **Tailwind CSS** — لأنماط الواجهة
- **Node.js**
- **Figma**

## 📁 هيكل المشروع

```
├── index.html      # الصفحة الرئيسية (كل الأقسام)
├── css/
│   └── style.css   # أنماط Tailwind المجمّعة + تخصيصات
├── js/
│   └── index.js    # السكربت: الوضع الليلي، الفلاتر، التنقل
├── imgs/           # الصور والأيقونات (mypic.jpg = الصورة الشخصية)
└── README.md
```

## ▶️ التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل سيرفر محلي:

```bash
npx serve .
# أو
python -m http.server 5502
```

ثم افتح `http://localhost:5502`

## ✨ المزايا

- تصميم Fully Responsive لكل الشاشات
- Dark / Light mode مع حفظ التفضيل
- فلترة المشاريع ديناميكيًا (ويب / تطبيقات / تصميم / تجارة إلكترونية)
- دعم RTL كامل للغة العربية
- تحسينات الأداء: تحميل مسبق للخطوط، تحميل كسول للصور، وخصائص `defer` / `async` غير حاجبة للـ CSS
